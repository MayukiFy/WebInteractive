## 🌟 จุดเด่นและฟังก์ชันการทำงาน

1. **การแก้ไข Navbar และ Footer จุดเดียว (Single Point of Truth)**:
   - จัดการโครงสร้าง Navbar และ Footer ผ่าน `assets/js/components.js`
   - เมื่อต้องการแก้ไขเมนู ลิงก์ หรือข้อความใน Footer สามารถแก้ที่ไฟล์นี้เพียงครั้งเดียว จะมีผลทันทีกับทุกหน้า

2. **ระบบ Dark / Light Mode**:
   - บันทึกการตั้งค่าลง `localStorage` จำค่าโหมดที่ผู้ใช้เลือกอัตโนมัติ
   - สลับสีพื้นหลัง สีข้อความ และกระจกฝ้า (Liquid Glass) อย่างนุ่มนวล

3. **ระบบเสียงดนตรีธรรมชาติในพื้นหลัง (Eco Ambient Soundscape)**:
   - จำลองเสียงดนตรีบำบัดสไตล์ธรรมชาติ (Harmonic Pentatonic Drone & Natural Chimes) ผ่าน **Web Audio API**
   - มีปุ่มเปิด/ปิดเสียง 2 จุด:
     - แถบเมนูด้านบน (Navbar) ถัดจากปุ่มสลับธีม
     - วิดเจ็ตลอยมุมล่างซ้าย (Floating Pill) พร้อมแถบ Equalizer กราฟิกเคลื่อนไหวตามจังหวะเสียง
   - ระบบ Fade-in / Fade-out นุ่มนวล ไม่สะดุดหู
   - บันทึกสถานะการเปิด/ปิดลง `localStorage` จำค่าต่อเนื่องเมื่อเปลี่ยนหน้า

4. **มินิเกม Eco Sort Challenge (60 วินาที)**:
   - จับเวลานับถอยหลัง 1 นาที (60 วินาที)
   - สุ่มขยะในชีวิตประจำวันมาให้ผู้เล่นจำแนกลงถัง 4 สี:
     - 🍏 ถังสีเขียว: ขยะเปียก / อินทรีย์
     - 📦 ถังสีเหลือง: ขยะรีไซเคิล
     - 🍟 ถังสีน้ำเงิน: ขยะทั่วไป
     - 🔋 ถังสีแดง: ขยะอันตราย
   - รองรับทั้งการ **ลากวางด้วยเมาส์ (Drag & Drop)** บนคอมพิวเตอร์ และ **แตะเลือกถัง (Touch/Tap)** บนมือถือและแท็บเล็ต
   - แยกถูก: ได้คะแนนสะสม (+10 ถึง +15 ตามระดับคอมโบ) พร้อมเสียงระฆังและเอฟเฟกต์สีเขียว
   - แยกผิด: โดนหัก -5 คะแนน พร้อมเสียงเตือนและแจ้งถังที่ถูกต้อง
   - สร้างเสียงเอฟเฟกต์ด้วย Web Audio API โดยไม่ต้องโหลดไฟล์เสียงภายนอก
   - หน้าต่างสรุปผลคะแนน ระดับเหรียญเกียรติยศ และปุ่มเริ่มเล่นใหม่

4. **ข้อมูลที่ถูกต้องตามหลักวิชาการ**:
   - มาตรฐานถังขยะ 4 สีตามข้อกำหนดของ **กรมควบคุมมลพิษ**
   - รหัสสัญลักษณ์ประเภทพลาสติก 1-7 (PET, HDPE, PVC, LDPE, PP, PS, OTHER)
   - แนวคิด **7R** (Rethink, Refuse, Reduce, Reuse, Repair, Recycle, Recover)
   - วิดีโอเพื่อการศึกษาฝังจาก **YouTube** แบบ Responsive 16:9

5. **สไตล์งานออกแบบระดับพรีเมียม (Modern Liquid Glass UI)**:
   - กระจกฝ้า `backdrop-filter: blur(16px)` แสงสะท้อนและเงาแบบเรืองแสง (Glow)
   - พื้นหลังภาพถ่ายคุณภาพสูงในทุกหน้าหลัก (Fixed Background Parallax)
   - ตัวอักษร Google Fonts: `Prompt` (ภาษาไทย) และ `Plus Jakarta Sans` (ภาษาอังกฤษและตัวเลข)
   - รองรับทุกขนาดหน้าจออย่างสมบูรณ์แบบ (Responsive 100%)
